# Sazid Alam - Portfolio Website

A modern, dark-themed portfolio website for Sazid Alam - Frontend Web Developer & UI/UX Designer.

## 🚀 Features

- **Modern Dark Theme**: Professional dark color scheme with purple-pink gradient accents
- **Advanced Animations**: Smooth scroll animations, hover effects, and micro-interactions
- **Fully Responsive**: Mobile-first design that works on all devices
- **Performance Optimized**: Fast loading with optimized assets and lazy loading
- **SEO Friendly**: Semantic HTML5 structure with proper meta tags
- **Accessible**: WCAG compliant with proper ARIA labels and keyboard navigation
- **Interactive Elements**: Contact form, skill bars, project cards, and more

## 🛠️ Technologies Used

- **HTML5**: Semantic markup with proper structure
- **CSS3**: Modern CSS with animations, transitions, and glassmorphism effects
- **Vanilla JavaScript**: No frameworks, pure JavaScript for maximum performance
- **Font Awesome**: Icon library for social links and UI elements
- **Google Fonts**: Inter font family for modern typography

## 🚀 Deployment

This website is designed to be deployed on GitHub Pages. To deploy:

1. Push the code to a GitHub repository
2. Enable GitHub Pages in repository settings
3. Select the main branch as source
4. The site will be available at `https://username.github.io/repository-name`

## 🌐 Customization

### Updating Personal Information
Edit the following in `index.html`:
- Name and role in hero section
- Bio text in about section
- Skills and progress percentages
- Project details and links
- Contact information

### Modifying Colors
Update CSS variables in `style.css`:
```css
:root {
    --primary-bg: #0a0a0a;
    --accent-primary: #8b5cf6;
    --accent-secondary: #ec4899;
    /* ... other variables */
}
```

### Adding Projects
Duplicate the project card structure in the projects section:
```html
<div class="project-card">
    <!-- Project content -->
</div>
```
